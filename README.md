# PingEZ - ネットワーク疎通確認ツール

> **確認専用ツールです。ネットワーク設定の変更は一切行いません。**

## 概要

`PingEZ.ps1` は、閉域Windows環境の管理者・ネットワーク担当者が  
ping / TCPポート確認 / tracert / DNS確認 を GUI から手軽に実行・記録できる  
PowerShell製の管理補助ツールです。

- インターネット接続不要
- 外部ライブラリ不要
- Windows PowerShell 5.1 対応
- 管理者権限不要（一般的な確認作業の場合）

---

## 実行方法

### 通常起動

PowerShell コンソールまたは右クリックメニューから実行します。

```powershell
# PowerShell コンソールから
.\PingEZ.ps1
```

### 実行ポリシーに関する注意

環境によってはスクリプトの実行が制限されている場合があります。  
その場合は、以下のいずれかの方法で実行してください。

```powershell
# 方法1: 現在のセッションのみポリシーを変更して実行
powershell.exe -ExecutionPolicy Bypass -File .\PingEZ.ps1

# 方法2: 右クリック → 「PowerShell で実行」が有効な環境では直接実行
```

**実行ポリシーの変更は必要最小限にとどめ、管理者が内容を確認したうえで実行してください。**

## 機能一覧

| 機能 | 説明 |
|------|------|
| **Ping 確認** | 宛先入力欄の各行に対して `Test-Connection` で疎通確認。成功/失敗・応答時間を表示 |
| **TCP ポート確認** | 宛先 × ポートの組み合わせで TCP 接続確認。タイムアウト 3 秒 |
| **Tracert 確認** | `tracert.exe` を呼び出してルート追跡結果を表示 |
| **DNS 確認** | ホスト名 → IP（正引き）、IP → ホスト名（逆引き）を確認 |
| **結果クリア** | 結果表示欄とログバッファをクリア |
| **結果保存** | TXT または CSV 形式で保存（ファイル名に日時を自動付与） |

## 入力形式

### 宛先

- 1行に1件、IPアドレスまたはホスト名を入力
- 空行は自動的に無視される

```
192.168.1.1
192.168.1.254
server01.example.local
10.0.0.1
```

### TCP ポート

- カンマ区切りで複数指定可能
- 使用可能範囲: 1〜65535

```
80,443,445,3389
```

## 結果保存

- 「結果を保存」ボタンをクリックするとファイル保存ダイアログが開く
- ファイル名はデフォルトで `nwcheck_YYYYMMDD_HHMMSS` が自動入力される
- TXT / CSV のいずれかを選択して保存
- 保存先はユーザーが自由に選択可能

## 注意事項

### 動作・機能について

- **本ツールはネットワーク設定を変更しない確認専用ツールです**
- Ping（ICMP）が遮断されている環境では ping 確認が失敗する場合があります
- tracert は環境やルーティング構成によって数十秒〜数分かかる場合があります
- TCP ポート確認が成功しても、アプリケーションレベルの正常性を保証するものではありません
- DNS 確認結果は、実行端末が参照している DNS サーバの設定に依存します

### 実行環境について

- Windows 10 / Windows 11 での動作を想定しています
- Windows PowerShell 5.1 で動作します
- PowerShell 7 (Core) でも動作しますが、テスト対象は 5.1 です
- 管理者権限がなくても実行できますが、環境によっては一部機能が制限される場合があります

### セキュリティについて

- 本ツールは外部への通信を行いません
- 認証情報の入力・保存機能はありません
- ネットワーク設定の変更機能は含まれていません
