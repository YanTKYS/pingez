# PingEZ - ネットワーク疎通確認ツール

> **確認専用ツールです。ネットワーク設定の変更は一切行いません。**
>
> バージョン: **0.1.0 実機検証版**

## 概要

`PingEZ.ps1` は、閉域Windows環境の管理者・ネットワーク担当者が  
ping / TCPポート確認 / tracert / DNS確認 を GUI から手軽に実行・記録できる  
PowerShell製の管理補助ツールです。

- インターネット接続不要
- 外部ライブラリ不要
- Windows PowerShell 5.1 対応
- 管理者権限不要（一般的な確認作業の場合）

---

## 実行方法

### 通常起動

PowerShell コンソールまたは右クリックメニューから実行します。

```powershell
# PowerShell コンソールから
.\PingEZ.ps1
```

### 実行ポリシーに関する注意

環境によってはスクリプトの実行が制限されている場合があります。  
その場合は、以下のいずれかの方法で実行してください。

```powershell
# 方法1: 現在のセッションのみポリシーを変更して実行
powershell.exe -ExecutionPolicy Bypass -File .\PingEZ.ps1

# 方法2: 右クリック → 「PowerShell で実行」が有効な環境では直接実行
```

**実行ポリシーの変更は必要最小限にとどめ、管理者が内容を確認したうえで実行してください。**

## 機能一覧

| 機能 | 説明 |
|------|------|
| **Ping 確認** | 宛先入力欄の各行に対して疎通確認。成功/失敗・応答時間を表示 |
| **TCP ポート確認** | 宛先 × ポートの組み合わせで TCP 接続確認。タイムアウト 3 秒。既知ポートはサービス名も表示 |
| **Tracert 確認** | `tracert.exe` を呼び出してルート追跡結果を表示。`* * *` ホップに「ICMP 無応答」を付記 |
| **DNS 確認** | ホスト名 → IP（正引き）、IP → ホスト名（逆引き）を確認。PTR レコードなしは明示 |
| **全確認** | Ping / TCP / DNS を一括実行（Tracert は除く） |
| **色分け表示** | 結果の行を内容に応じて色分け（緑=成功、黄=タイムアウト、赤=失敗/エラー、橙=スキップ、青=見出し） |
| **ポートサービス名表示** | TCP確認時に既知ポート番号のサービス名（HTTP, RDP, SMB 等）を自動表示 |
| **宛先リスト保存** | 宛先入力欄の内容をTXTファイルに保存して再利用 |
| **宛先リスト読込** | 保存済みTXTファイルから宛先を読み込み（`#` 行はコメントとして無視） |
| **結果クリア** | 結果表示欄とログバッファをクリア |
| **結果保存** | TXT または CSV 形式で保存（ファイル名に日時を自動付与） |

## 入力形式

### 宛先

- 1行に1件、IPアドレスまたはホスト名を入力
- 空行は自動的に無視される
- 起動時は宛先欄が空白の状態です。必要に応じて入力してください

```
192.168.1.1
192.168.1.254
server01.example.local
10.0.0.1
```

### TCP ポート

- カンマ区切りで複数指定可能
- 使用可能範囲: 1〜65535

```
80,443,445,3389
```

## 色分け表示

結果欄の各行は内容に応じて色分けされます。

| 色 | 意味 |
|----|------|
| 緑 | 成功（Ping応答あり、ポートOpen、DNS解決成功） |
| 黄 | タイムアウト・ICMP無応答 |
| 赤 | 失敗・エラー |
| 橙 | スキップ（不正な入力文字のため処理を省略） |
| 青 | セクション見出し（`===` 区切り行） |
| 薄緑 | その他の情報行 |

---

## ポートサービス名表示

TCP ポート確認時、既知のポート番号に対してサービス名を自動付与します。

```
[192.168.1.1:80]   (HTTP)   成功 (Open)
[192.168.1.1:443]  (HTTPS)  成功 (Open)
[192.168.1.1:3389] (RDP)    失敗 (Refused - ポート閉鎖)
```

対応済みの主なポート: FTP(21), SSH(22), SMTP(25), DNS(53), HTTP(80), HTTPS(443), SMB(445), RDP(3389) ほか計31種

## 宛先リストの保存・読込

繰り返し確認する宛先を TXT ファイルに保存して再利用できます。

### 保存

1. 宛先欄に宛先を入力した状態で「リスト保存」ボタンをクリック
2. 保存先とファイル名を指定して保存

### 読込

1. 「リスト読込」ボタンをクリック
2. 保存済みの TXT ファイルを選択
3. 宛先欄に自動入力される

### ファイル形式

```
# デフォルトゲートウェイ
192.168.1.1

# 主要サーバ
192.168.1.10
192.168.1.20
server01.example.local
```

`#` で始まる行はコメントとして読み込み時に無視されます。

## 結果保存

- 「結果を保存 (TXT/CSV)」ボタンをクリックするとファイル保存ダイアログが開く
- ファイル名はデフォルトで `nwcheck_YYYYMMDD_HHMMSS` が自動入力される
- 保存先はユーザーが自由に選択可能

### 保存形式について

| 形式 | 位置づけ |
|------|------|
| **TXT（推奨）** | ログをそのままテキスト保存。主な保存形式。報告・問い合わせに最適 |
| CSV | ログ行を1列（1セル）として保存する簡易形式。Excel で開けるが集計向きではない |

> **注意**: CSV保存は現バージョンでは「ログ1行 = 1セル」の簡易形式です。  
> 宛先・結果・応答時間などを列ごとに分けた集計向けCSVは今後の改善候補です。  
> 現時点では **TXT保存を主な保存形式**として使用してください。

## 既知の制約（v0.1.0）

| 制約 | 内容 |
|------|------|
| Tracert の実行時間 | 途中のルータが ICMP を返さない環境では `* * *` が続き、完了まで最大60秒かかることがあります |
| CSV は簡易形式 | 1行 = 1セルの単純な出力です。列分割・集計には不向きです |
| 非同期実行なし | 実行中はボタンがすべて無効化されます。大量の宛先や Tracert 実行中は画面の応答が遅くなる場合があります |
| 文字コード依存 | Tracert の出力はCP932（Shift-JIS）でデコードしています。稀な文字コード環境では文字化けの可能性があります |

## 注意事項

### 動作・機能について

- **本ツールはネットワーク設定を変更しない確認専用ツールです**
- Ping（ICMP）が遮断されている環境では ping 確認が失敗する場合があります
- tracert は環境やルーティング構成によって数十秒〜最大60秒かかる場合があります
- TCP ポート確認が成功しても、アプリケーションレベルの正常性を保証するものではありません
- DNS 確認結果は、実行端末が参照している DNS サーバの設定に依存します

### 実行環境について

- Windows 10 / Windows 11 での動作を想定しています
- Windows PowerShell 5.1 で動作します
- PowerShell 7 (Core) でも動作しますが、テスト対象は 5.1 です
- 管理者権限がなくても実行できますが、環境によっては一部機能が制限される場合があります

### セキュリティについて

- 本ツールは外部への通信を行いません
- 認証情報の入力・保存機能はありません
- ネットワーク設定の変更機能は含まれていません
- 入力値はコマンドライン文字列へ直接連結せず、使用可能文字（英数字・ドット・ハイフン等）のみを許可しています
